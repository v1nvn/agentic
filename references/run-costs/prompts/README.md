# Subagent briefs — verbatim

Six sonnet general-purpose subagents produced the interpretation layer; the numbers
they returned are in `../reports/d7ab34d2.md`. Wave 1 (four, parallel): parent
ledger, builders, reviewers+clerk, cross-agent waste. Wave 2 (two, parallel):
token ledgers. Each brief carries its own parsing contract — a brief is the parsing
law in executable prose, so a future run adapts the brief, not just the script.

- `01-parent-ledger.md` — per-turn ledger, dispatch overhead, hand-back latency,
  SendMessage rounds, reconciliation.
- `02-builders.md` — context-build phase (spawn→first Edit), phase breakdowns,
  within-agent redundancy.
- `03-reviewers-clerk.md` — what each verification role re-did, clerk burst
  inventory.
- `04-waste.md` — gate-run inventory with root-vs-scoped pricing, duplicate work,
  cold-start re-read multiplication, dead moves.
- `05-tokens-parent-builders.md` — usage schema hunt, per-agent token ledger,
  phase attribution, standing-context tax, parent curve.
- `06-tokens-verification.md` — spawn-injection economics, cross-agent re-read
  token cost, killed-agent cost, grand totals.
