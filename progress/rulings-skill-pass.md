# Rulings — skill pass: authoring friction and the quick bridge

## Goal

The consult skill stops fighting its own contract: every authoring rule
that a real build tripped on is fixed or deleted, and the owner's
expectation — a rulings page minted from evidence the consulting agent
already holds in seconds, not a 35-minute report run — is either built as
a fast path or re-scoped by ruling.

## Current state

Findings from the sample build of `~/.claude/rulings/agentic-open-surfaces/`
(the content exemplar), nowhere else recorded:

- Step 5's npx pin has no build-from-source door — the branch engine
  cannot be exercised by the skill's own build command.
- The 76-char body cap fights "copy the real body verbatim".
- `in` vs `o:"del"` has no stated convention for the same disappearance.
- The stake-number validator passes on anchor digits alone.
- The similarity validator is gameable — authors dodge the meter.
- `cap` + gain state the same conclusion twice by construction.
- The bodies door never invites `.md` surfaces (worked via `lang: markup`).
- The seed example uses double quotes against the field law's single.
- `w` is missing from Step 4's option rules.

The bigger open question from the same sitting: the skill is a
report-writing discipline, not a quick bridge. No fast path exists for
minting a page from evidence the consulting agent already holds.
